TELEGRAM-БОТ «СЛОВАРЬ СОВРЕМЕННОГО РУССКОГО СЛЕНГА»

1. Установите Python.
2. Откройте терминал в папке проекта.
3. Выполните:
   pip install -r requirements.txt

4. Откройте bot.py.
5. В строке TOKEN вставьте токен, который вы получили у @BotFather.
6. Запустите:
   python bot.py

7. Откройте своего бота в Telegram и отправьте /start.

Чтобы добавить свои слова, откройте slang_dict.py и добавьте новую запись по образцу.

ВАЖНО:
Не публикуйте токен бота в интернете и не отправляйте его другим людям.
